# Home Automation Stack - HA + Node-RED + Zigbee

智能家居自动化栈，提供完整的家庭自动化解决方案。

## 服务组成

- **Home Assistant**: 智能家居控制中心
- **Node-RED**: 可视化流程编程
- **Zigbee2MQTT**: Zigbee 设备桥接
- **MQTT Broker**: 消息队列服务

## 部署说明

```bash
cd stacks/home-automation
docker compose up -d
```
