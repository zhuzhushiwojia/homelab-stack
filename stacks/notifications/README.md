# Notifications Stack - Gotify + Apprise

统一通知中心，为所有 Homelab 服务提供通知推送能力。

## 服务组成

- **Gotify**: 消息推送服务
- **Apprise**: 通知聚合网关

## 部署说明

```bash
cd stacks/notifications
docker compose up -d
```
